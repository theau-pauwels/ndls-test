# Nederlands Lab

Application Astro de révision du néerlandais pour le test UMONS (leçons 1 à 4 et exercices Moodle).

## Démarrer

```bash
npm install
npm run dev
```

Déploiement Vercel : importer ce dépôt, framework Astro, commande `npm run build`, dossier `dist`.

Fonctions : flashcards FR ↔ NL, pratique écrite, exercices sur l'heure, grammaire et mises en situation, répétition espacée locale, examen blanc configurable avec correction finale. Aucune connexion ni base de données nécessaires. La progression est stockée localement dans le navigateur.

## Sources

Vocabulaire et grammaire : synthèse *Basiskennis Nederlands*, cours de M. Boussauw, UMONS, et exercices Moodle fournis. Le jeu de questions spécifiques complète les cartes de vocabulaire.
